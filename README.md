# Sistema de Gerenciamento de Operações Portuárias 🚢

Plataforma web desenvolvida para auxiliar no controle e gerenciamento das operações com embarcações na região da Ponta da Madeira, facilitando o acompanhamento de navios, a disponibilidade de espaços para carga e descarga e a geração de relatórios operacionais em PDF.

## Sobre o projeto

Este projeto surgiu a partir de uma necessidade real da operação portuária: centralizar informações operacionais em um único lugar, tornando o acompanhamento das embarcações mais organizado, prático e eficiente.

A plataforma permite registrar e acompanhar informações sobre os navios, gerenciar espaços disponíveis para carregamento e descarregamento e gerar um relatório final em PDF, facilitando o compartilhamento dos dados com a equipe no grupo de operações.

O objetivo é reduzir a dependência de controles manuais, melhorar a organização das informações e agilizar a comunicação durante a rotina operacional.

## Funcionalidades

- **Gerenciamento de embarcações:** controle e acompanhamento das informações dos navios.
- **Controle de espaços operacionais:** visualização e gerenciamento dos espaços livres para carregamento e descarregamento.
- **Organização das informações:** centralização dos dados operacionais em uma interface simples e intuitiva.
- **Geração de relatórios em PDF:** criação de relatórios finais com as informações da operação.
- **Compartilhamento de relatórios:** facilidade para enviar os documentos gerados ao grupo de operações.
- **Interface web:** acesso às funcionalidades por meio de uma plataforma digital.

## Objetivo

Desenvolver uma solução digital simples e funcional para otimizar o controle operacional de embarcações, facilitar o acompanhamento dos espaços disponíveis e melhorar o fluxo de compartilhamento de informações entre os profissionais envolvidos na operação.

## Tecnologias utilizadas

- HTML5
- CSS3
- JavaScript
## Aplicação prática

A plataforma foi desenvolvida para atender a uma necessidade real de um profissional que trabalha com operações de embarcações na Ponta da Madeira, transformando uma rotina de controle operacional em um processo mais organizado e digital.

Além de facilitar o gerenciamento diário, o sistema permite consolidar as informações em um documento PDF, tornando mais simples a comunicação dos dados com os demais integrantes da equipe.
